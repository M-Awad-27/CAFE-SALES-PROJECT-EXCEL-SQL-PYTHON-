# ☕ Cafe Sales Analysis Project  
**Excel | SQL | Python**

## 📌 Project Overview  
This project analyzes cafe sales data to uncover meaningful business insights using **Excel**, **SQL**, and **Python**. It demonstrates an end-to-end data analysis workflow—from raw data cleaning to actionable insights—focused on sales trends, product performance, and revenue patterns.

The goal of this project is to showcase practical data analytics skills using multiple tools commonly applied in real-world business scenarios.

---

## 🎯 Objectives  
- Clean and prepare raw cafe sales data  
- Analyze sales performance across products and time periods  
- Identify top-selling items and revenue drivers  
- Discover trends and patterns to support business decision-making  
- Demonstrate proficiency in Excel, SQL, and Python  

---

## 🛠️ Tools & Technologies  

### Excel  
- Data cleaning  
- Pivot tables  
- Summary reports and charts  

### SQL  
- Data querying  
- Aggregations and joins  
- Sales and revenue analysis  

### Python  
- Data manipulation using `pandas`  
- Exploratory Data Analysis (EDA)  
- Data visualization using `matplotlib` and `seaborn`
